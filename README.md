# DANGI KURDISTAN

Voice chat rooms, gifts, games and messages for Kurds worldwide.

## Deploy on Vercel
1. Upload this folder to a GitHub repository.
2. On vercel.com, click "Add New → Project", import the repository, and click "Deploy".
No build step is needed: it's a single static `index.html`.

Note: this hosted copy runs in preview mode — each visitor's data stays in their own browser tab.
Shared rooms, real accounts and saved data need a backend (for example Firebase).
